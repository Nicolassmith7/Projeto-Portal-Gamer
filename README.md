# 🎮 Portal de Games

Projeto desenvolvido como parte do meu portfólio, unindo minha paixão por games com o desenvolvimento web. O Portal de Games é uma plataforma informativa com seções de notícias, análises, trailers e curiosidades do mundo gamer.

## 🔧 Tecnologias utilizadas
- HTML5  
- CSS3  
- Bootstrap  
- JavaScript

## 📱 Funcionalidades
- Layout responsivo
- Navegação intuitiva
- Conteúdo dinâmico sobre games
- 
## 🚀 Como visualizar o projeto
Você pode baixar os arquivos e abrir o `index.html` no navegador.
